## Tech Stack

- **Frontend**: Next.js 14, React 18, TypeScript, Tailwind CSS
- **Backend**: Node.js, Express/Fastify
- **Database**: PostgreSQL with Prisma ORM
- **Animations**: Framer Motion, GSAP
- **Components**: Radix UI, Headless UI
- **State**: Zustand or React Context
- **Auth**: NextAuth.js or Clerk
- **Deployment**: Vercel

## Awwwards Quality Standards

- Performance: 90+ Lighthouse score
- Accessibility: WCAG 2.1 AA compliant
- Mobile-first responsive design
- Smooth 60fps animations
- Semantic HTML
- SEO optimized
- Type-safe throughout

## How It Works

1. **Product Strategist** defines what we're building
2. **Creative Director** designs the visual language
3. **UX Architect** plans user flows and interactions
4. **Tech Lead** chooses the architecture
5. **Backend Developer** builds the API
6. **Frontend Developer** builds the Next.js app
7. **Database Architect** designs the data layer
8. **UI Engineer** creates component library
9. **Animation Developer** adds motion design
10. **Content Strategist** writes copy
11. **QA Engineer** tests everything
12. **Performance Engineer** optimizes
13. **Polish Specialist** final review
14. **Conductor** manages the flow

## Communication

All agents communicate through `.jules/` directory:
- `/strategy/` - Product decisions
- `/design/` - Visual designs
- `/architecture/` - Technical specs
- `/code/` - Code reviews
- `/content/` - Copy and assets
- `/tickets/` - Blockers and issues
- `/log.md` - Daily activity log

## Key Improvements Over Previous System

1. **Focused scope**: Only Next.js + Node.js websites
2. **Better flow**: Design → Architecture → Code → Content → Polish
3. **Clearer dependencies**: Each agent has 1-2 specific dependencies
4. **Awwwards standards**: Quality benchmarks built in
5. **Simpler coordination**: Less agents blocking each other
6. **Modern stack**: Latest Next.js, TypeScript, Tailwind

## Getting Started

1. Create `.jules/website-idea.md` with your concept
2. Conductor will create the schedule at 08:00
3. Agents will build the site throughout the day
4. By 22:00, you'll have a working website
